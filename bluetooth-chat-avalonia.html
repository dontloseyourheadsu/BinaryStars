Bluetooth Chat
Avalonia · .NET 10 · Linux & Android

Architecture, device setup, library selection, full code structure, and UML system diagram
for cross-device text and file transfer via Bluetooth Classic RFCOMM.

1 — Library Decision

✔ Chosen: InTheHand.Net.Bluetooth (32feet.NET) v4.2.4 The only production-ready, actively maintained .NET Bluetooth library that simultaneously covers Linux (via BlueZ native sockets), Android (.NET for Android), and is explicitly confirmed to work in Avalonia. It targets .NET Standard 2.0, making it compatible with .NET 10. Last updated April 2026.
Library Linux Android Avalonia confirmed .NET 10 Classic BT (RFCOMM)
InTheHand.Net.Bluetooth 4.2.4 ✔ BlueZ sockets ✔ ✔ explicit blog post ✔ via netstandard2.0 ✔ primary feature
InTheHand.BluetoothLE 4.0.44 BLE only BLE only ✔ ✔ ✗ BLE only, small MTU
Linux.Bluetooth (SuessLabs) ✔ DBus/BlueZ ✗ untested ✔ ✗ BLE only
Plugin.BLE (Shiny) ✗ BLE only ✗ partial ✗

For file transfer over Classic Bluetooth RFCOMM, InTheHand.Net.Bluetooth is the only viable choice that works across both target platforms inside an Avalonia project.

⚠ Important Limitation The Linux implementation uses native P/Invoke AF_BLUETOOTH sockets (not D-Bus) on .NET 6+. This requires BlueZ kernel modules and bluetoothd to be running, and the pairing must be done via bluetoothctl before connecting in code. Device discovery on Linux also depends on BlueZ being accessible to the process user (usually requires the user to be in the bluetooth group).

3 — Device Setup

Linux Setup
  1. Install BlueZ and D-Bus tools:
    sudo apt install bluez bluez-tools
  2. Add your user to the bluetooth group:
    sudo usermod -aG bluetooth $USER
    then log out and back in.
  3. Enable and start bluetoothd:
    sudo systemctl enable --now bluetooth
  4. Pair the remote device:
    bluetoothctl
    power on
    agent on
    scan on
    pair <MAC>
    trust <MAC>
  5. Verify RFCOMM kernel module:
    lsmod | grep rfcomm
    If missing: sudo modprobe rfcomm
Android Setup
  1. Declare permissions in AndroidManifest.xml (see code block below).
  2. Request runtime permissions on app launch (API 31+ requires BLUETOOTH_CONNECT, BLUETOOTH_SCAN at runtime).
  3. Enable Bluetooth and make the device discoverable from Settings → Bluetooth.
  4. Pair with the target device from Android Settings. The app connects after pairing.
  5. Override MainActivity.OnCreate to set InTheHand.AndroidActivity.CurrentActivity — required for 32feet on Avalonia Android (see code).

BluetoothMessage.cs — wire protocol

C#namespace BluetoothChat.Core;

public enum MessageType : byte { Text = 1, FileTransfer = 2, Handshake = 3 }

public sealed class BluetoothMessage
{
    public MessageType Type     { get; init; }
    public string?     Text     { get; init; }
    public string?     FileName { get; init; }
    public byte[]?     FileData { get; init; }
    public DateTimeOffset Timestamp { get; init; } = DateTimeOffset.UtcNow;

    // Wire format: [1 byte type][4 bytes payload length][payload bytes]
    // Text payload:  UTF-8 string
    // File payload:  [2 bytes name-length][name UTF-8][file bytes]
    public byte[] Serialize()
    {
        using var ms = new MemoryStream();
        using var bw = new BinaryWriter(ms, System.Text.Encoding.UTF8, leaveOpen: true);
        bw.Write((byte)Type);
        if (Type == MessageType.Text)
        {
            var body = System.Text.Encoding.UTF8.GetBytes(Text ?? "");
            bw.Write(body.Length);
            bw.Write(body);
        }
        else if (Type == MessageType.FileTransfer)
        {
            var nameBytes = System.Text.Encoding.UTF8.GetBytes(FileName ?? "file");
            var data      = FileData ?? [];
            bw.Write(nameBytes.Length + data.Length + 2);
            bw.Write((short)nameBytes.Length);
            bw.Write(nameBytes);
            bw.Write(data);
        }
        return ms.ToArray();
    }

    public static BluetoothMessage Deserialize(byte[] raw)
    {
        using var ms = new MemoryStream(raw);
        using var br = new BinaryReader(ms, System.Text.Encoding.UTF8, leaveOpen: true);
        var type    = (MessageType)br.ReadByte();
        var payLen  = br.ReadInt32();
        if (type == MessageType.Text)
        {
            var text = System.Text.Encoding.UTF8.GetString(br.ReadBytes(payLen));
            return new BluetoothMessage { Type = type, Text = text };
        }
        else // FileTransfer
        {
            var nameLen  = br.ReadInt16();
            var name     = System.Text.Encoding.UTF8.GetString(br.ReadBytes(nameLen));
            var fileData = br.ReadBytes(payLen - nameLen - 2);
            return new BluetoothMessage { Type = type, FileName = name, FileData = fileData };
        }
    }
}

MessageFramer.cs — length-prefix framing over streams

C#namespace BluetoothChat.Core;

/// Writes/reads length-prefixed frames so messages are reliably delimited
/// across the raw RFCOMM stream.
public static class MessageFramer
{
    public static async Task WriteFrameAsync(Stream stream, byte[] payload,
        CancellationToken ct)
    {
        var lenBuf = BitConverter.GetBytes(payload.Length); // 4 bytes LE
        await stream.WriteAsync(lenBuf, ct);
        await stream.WriteAsync(payload, ct);
        await stream.FlushAsync(ct);
    }

    public static async Task<byte[]?> ReadFrameAsync(Stream stream,
        CancellationToken ct)
    {
        var lenBuf = new byte[4];
        if (!await ReadExactAsync(stream, lenBuf, ct)) return null;
        var length = BitConverter.ToInt32(lenBuf);
        if (length is <= 0 or > 50_000_000) return null; // 50 MB safety cap
        var payload = new byte[length];
        return await ReadExactAsync(stream, payload, ct) ? payload : null;
    }

    static async Task<bool> ReadExactAsync(Stream s, byte[] buf, CancellationToken ct)
    {
        int offset = 0;
        while (offset < buf.Length)
        {
            var read = await s.ReadAsync(buf.AsMemory(offset), ct);
            if (read == 0) return false;
            offset += read;
        }
        return true;
    }
}

BluetoothChatService.cs — platform-agnostic orchestrator

C#using System.Reactive.Subjects;
using InTheHand.Net;
using InTheHand.Net.Sockets;

namespace BluetoothChat.Core;

public sealed class BluetoothChatService
{
    // Shared service UUID — must be identical on all devices
    public static readonly Guid ServiceUuid =
        new("3a0d9440-7b5b-4f5a-b0a3-00112233aabb");

    private readonly IBluetoothService _bt;
    private readonly Subject<BluetoothMessage> _messages = new();

    public IObservable<BluetoothMessage> Messages    => _messages;
    public IObservable<ConnectionState>  StateChanges => _bt.ConnectionStateChanged;

    public BluetoothChatService(IBluetoothService bluetoothService)
    {
        _bt = bluetoothService;
        _bt.MessageReceived.Subscribe(m => _messages.OnNext(m));
    }

    public Task<IEnumerable<BluetoothDeviceInfo>> DiscoverAsync(CancellationToken ct = default)
        => _bt.DiscoverDevicesAsync(ct);

    public Task ListenAsync(CancellationToken ct = default)
        => _bt.StartListeningAsync(ServiceUuid, ct);

    public Task ConnectToAsync(BluetoothAddress address, CancellationToken ct = default)
        => _bt.ConnectAsync(address, ServiceUuid, ct);

    public Task SendTextAsync(string text, CancellationToken ct = default)
        => _bt.SendMessageAsync(new BluetoothMessage { Type = MessageType.Text, Text = text }, ct);

    public async Task SendFileAsync(string filePath, CancellationToken ct = default)
    {
        var data = await File.ReadAllBytesAsync(filePath, ct);
        await _bt.SendMessageAsync(new BluetoothMessage
        {
            Type     = MessageType.FileTransfer,
            FileName = Path.GetFileName(filePath),
            FileData = data
        }, ct);
    }

    public void Disconnect() => _bt.Disconnect();
}

LinuxBluetoothService.cs

C#using System.Reactive.Subjects;
using InTheHand.Net;
using InTheHand.Net.Bluetooth;
using InTheHand.Net.Sockets;
using BluetoothChat.Core;

namespace BluetoothChat.Linux;

/// Uses InTheHand.Net.Bluetooth 4.2.4 which P/Invokes AF_BLUETOOTH
/// sockets directly on Linux (no D-Bus layer needed at this level).
public sealed class LinuxBluetoothService : IBluetoothService, IAsyncDisposable
{
    private readonly Subject<BluetoothMessage> _msgs  = new();
    private readonly Subject<ConnectionState>  _state = new();

    private BluetoothListener? _listener;
    private BluetoothClient?   _client;
    private Stream?            _stream;
    private CancellationTokenSource _cts = new();

    public IObservable<BluetoothMessage> MessageReceived        => _msgs;
    public IObservable<ConnectionState>  ConnectionStateChanged => _state;

    public async Task<IEnumerable<BluetoothDeviceInfo>> DiscoverDevicesAsync(
        CancellationToken ct = default)
    {
        _state.OnNext(ConnectionState.Discovering);
        using var bc = new BluetoothClient();
        var devices = bc.DiscoverDevices(maxDevices: 20); // synchronous on Linux
        _state.OnNext(ConnectionState.Disconnected);
        return devices;
    }

    public async Task StartListeningAsync(Guid serviceUuid, CancellationToken ct = default)
    {
        _state.OnNext(ConnectionState.Listening);
        _listener = new BluetoothListener(serviceUuid);
        _listener.Start();
        // AcceptBluetoothClient blocks — run on thread pool
        _client = await Task.Run(() => _listener.AcceptBluetoothClient(), ct);
        _stream = _client.GetStream();
        _state.OnNext(ConnectionState.Connected);
        _ = ReadLoopAsync(_cts.Token);
    }

    public async Task ConnectAsync(BluetoothAddress address, Guid serviceUuid,
        CancellationToken ct = default)
    {
        _state.OnNext(ConnectionState.Connecting);
        _client = new BluetoothClient();
        await _client.ConnectAsync(address, serviceUuid);
        _stream = _client.GetStream();
        _state.OnNext(ConnectionState.Connected);
        _ = ReadLoopAsync(_cts.Token);
    }

    public async Task SendMessageAsync(BluetoothMessage message,
        CancellationToken ct = default)
    {
        if (_stream is null) throw new InvalidOperationException("Not connected.");
        await MessageFramer.WriteFrameAsync(_stream, message.Serialize(), ct);
    }

    public void Disconnect()
    {
        _cts.Cancel();
        _stream?.Close();
        _client?.Close();
        _listener?.Stop();
        _state.OnNext(ConnectionState.Disconnected);
    }

    private async Task ReadLoopAsync(CancellationToken ct)
    {
        try
        {
            while (!ct.IsCancellationRequested && _stream is not null)
            {
                var frame = await MessageFramer.ReadFrameAsync(_stream, ct);
                if (frame is null) break;
                _msgs.OnNext(BluetoothMessage.Deserialize(frame));
            }
        }
        catch { }
        finally { _state.OnNext(ConnectionState.Disconnected); }
    }

    public async ValueTask DisposeAsync()
    {
        Disconnect();
        await _cts.CancelAsync();
        _cts.Dispose();
    }
}

MainActivity.cs — critical Avalonia Android hook

C#using Android.App;
using Android.OS;
using Avalonia.Android;
using Microsoft.Extensions.DependencyInjection;
using BluetoothChat.Android;
using BluetoothChat.Core;

namespace BluetoothChat.Mobile;

[Activity(Theme = "@style/Theme.AppCompat.DayNight.NoActionBar",
          MainLauncher = true)]
public class MainActivity : AvaloniaMainActivity<App>
{
    protected override void OnCreate(Bundle? savedInstanceState)
    {
        // ⚠️ Required: 32feet needs a reference to the current Android Activity
        // to open Bluetooth intents (device picker, pairing, etc.)
        InTheHand.AndroidActivity.CurrentActivity = this;
        base.OnCreate(savedInstanceState);
        RequestBluetoothPermissions();
    }

    private void RequestBluetoothPermissions()
    {
        if (Build.VERSION.SdkInt >= BuildVersionCodes.S)
        {
            RequestPermissions(new[]
            {
                "android.permission.BLUETOOTH_SCAN",
                "android.permission.BLUETOOTH_CONNECT",
                "android.permission.BLUETOOTH_ADVERTISE"
            }, requestCode: 1001);
        }
        else
        {
            RequestPermissions(new[]
            {
                "android.permission.BLUETOOTH",
                "android.permission.BLUETOOTH_ADMIN",
                "android.permission.ACCESS_FINE_LOCATION"
            }, requestCode: 1000);
        }
    }
}

7 — Key Gotchas & Workarounds

  • Linux discovery is synchronous. BluetoothClient.DiscoverDevices() blocks the calling thread on Linux. Always wrap it in Task.Run().
  • Linux user permissions. The process user must be in the bluetooth group or running as root. Without this, socket creation silently fails.
  • InTheHand.AndroidActivity.CurrentActivity is mandatory on Avalonia Android. Without overriding MainActivity.OnCreate to set this, device discovery (which requires an Intent) will throw a NullReferenceException.
  • Runtime permissions on Android 12+. Even with manifest declarations, you must request BLUETOOTH_CONNECT and BLUETOOTH_SCAN at runtime. Without them, DiscoverDevices returns an empty list silently.
  • The server-side UUID must match exactly. Use the same static readonly Guid ServiceUuid in both apps — this is how RFCOMM SDP lookup finds the right service.
  • Large files. For files over ~5 MB, consider chunking: send file metadata first (name, total size), then multiple frames, then an end-of-file marker. The current SendFileAsync reads the whole file into memory — fine for small files.
  • Avalonia v12 vs v11. Avalonia 12.0.3 (May 2026) is the latest and supports .NET 10 cleanly. Use it; v11 on .NET 10 may have minor API mismatches in the MAUI backend.
